## 잔여 위험

MFA, 분산 rate limiter/Socket adapter, malware sandbox, 객체 스토리지, 중앙 SIEM은 단일 노드 학습 범위를 넘어 운영 전 추가해야 한다. E2E 데이터 자동 청소와 multi-browser matrix도 후속 개선이다.
